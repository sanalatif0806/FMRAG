# =============================================================================
# FMRAG REQUIREMENTS — Python 3.10 (Ubuntu 22.04 Jammy), CPU-only
# =============================================================================
#
# !! DO NOT run a bare `pip install -r requirements.txt` on a fresh venv. !!
#
# Why: pyhealth==1.1.4 only declares `torch>=1.8.0`, so if pip is allowed to
# resolve it freely it will pull the LATEST GPU torch (2.12+cu130) plus a
# ~6 GB NVIDIA CUDA stack — which breaks torch_scatter/torch_sparse (built
# for torch 2.2) and segfaults torch_geometric. Several packages also drag
# numpy back up to 2.x, which is ABI-incompatible with torch 2.2 and
# segfaults on import.
#
# Use the phased install below (or just run ./install_deps.sh, which does
# exactly this). The ORDER and the --no-deps flags are load-bearing, not
# cosmetic — every one of them corresponds to a real failure hit during
# deployment.
#
# -----------------------------------------------------------------------------
# PHASE 0 — system build deps (apt, NOT pip) — needed to compile mysqlclient:
#   sudo apt install -y python3.10-dev default-libmysqlclient-dev \
#                       build-essential pkg-config
#
# PHASE 1 — numpy FIRST, pinned <2 (torch 2.2 needs NumPy 1.x ABI):
#   pip install "numpy==1.26.4"
#
# PHASE 2 — torch CPU build, from the CPU index (NOT regular PyPI):
#   pip install torch==2.2.0 torchvision==0.17.0 torchaudio==2.2.0 \
#     --index-url https://download.pytorch.org/whl/cpu
#
# PHASE 3 — torch-geometric companions, matched to torch 2.2 + cpu:
#   pip install torch-geometric==2.5.2 torch-scatter==2.1.2 torch-sparse==0.6.18 \
#     -f https://data.pyg.org/whl/torch-2.2.0+cpu.html
#
# PHASE 4 — everything else, WITHOUT letting pip touch torch/numpy again:
#   pip install -r requirements.txt --no-deps
#   pip install -r requirements.txt          # second pass picks up sub-deps
#                                             # of the phase-4 packages only,
#                                             # torch/numpy already satisfied
#
# PHASE 5 — verify:
#   python -c "import torch, torch_geometric, torch_scatter, torch_sparse, \
#     yaml, gevent, flask, pyhealth, pandas, numpy; \
#     print('torch:', torch.__version__, '| numpy:', numpy.__version__, \
#     '| pandas:', pandas.__version__); print('ALL OK')"
#   # MUST show: torch 2.2.0+cpu, numpy 1.26.4, pandas 1.5.3, ALL OK
# =============================================================================
